## Icon References Used

- **Source**: `assets/images/orb_icon.png`
- **Usage**: App launcher icon, large notification icon, all platforms
- **Benefits**: Brand consistency across all surfaces

### Notification Icon
- **Source**: `android/app/src/main/res/drawable/notification_icon.xml`
- **Type**: Vector drawable (SVG-like XML)
- **Design**: White checkmark on dark circular background
- **Benefits**: 
  - Always crisp at any size (vector-based)
  - Follows Material Design notification guidelines
  - Works with Android's automatic tinting
  - Consistent across all densities

## Notification Behavior

### When Icons Are Displayed
1. **Small Icon** (in status bar and notification header)
   - Automatically displayed by Android system
   - Should be simple and recognizable
   - Will be tinted by system

2. **Large Icon** (in expanded notification)
   - Shown when user expands the notification
   - Can be colorful (uses the actual asset)
   - Provides visual branding

3. **Color Tinting** (notification header area)
   - Applied to small icon in status bar
   - Used: Deep purple (#673AB7) from app theme

## Best Practices Applied

1. **Vector Drawables**: Used XML-based vectors for notification icons
   - Scalable without pixelation
   - Works across all Android versions
   - Smaller file size

2. **Consistent Branding**: 
   - Used app icon for large notification preview
   - Used theme color for notification tinting
   - Maintained visual consistency

3. **Android Compliance**:
   - Notification icons are monochrome (white on transparent)
   - Proper transparency handling
   - Follows Material Design guidelines

4. **Cross-Platform Support**:
   - Configured icons for all supported platforms
   - Optimized for each platform's design patterns
   - Consistent user experience
